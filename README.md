roject Name: The Literary Hub: Secure Inventory & Sales Management System
This project is a robust, full-stack web application designed to streamline inventory control and sales tracking for retail environments. Developed as a complete solution, it serves as a strong demonstration of proficiency across the entire web development stack, focusing on security, data integrity, and real-time functionality.

Technical Achievements
The application is built on a strong foundation using PHP for all server-side logic and MySQL for persistent data management. The front-end leverages HTML5 and CSS3 for a clean, modern user experience.

One of the core features is the Secure Authentication System. I implemented a session-based login module to protect all management pages, ensuring only authenticated administrators can access and modify sensitive data. This security extends to a complete CRUD (Create, Read, Update, Delete) dashboard, allowing seamless, real-time management of the book inventory.

A key technical achievement is the Dynamic Live Search functionality. The public-facing catalog uses JavaScript and AJAX to query the database instantly for results based on title, author, or the unique ISBN identifier, providing an immediate and modern user experience without requiring a page refresh. Furthermore, the database schema was carefully constructed to enforce data integrity, particularly by relying on the ISBN as the unique product identifier.

This structured codebase, organized with separate modules for database connection and authentication, confirms adherence to professional software engineering best practices, making the application highly maintainable and ready for future scaling.
